\section{腔体可视化与交互对照}

腔体按家用蒸烤箱的可见零件建模。外壳为深色钢板，夹层为岩棉色保温块，内衬为圆角拉丝不锈钢。门框用黄铜条和橡胶密封条勾边，门玻璃做成内外两层，中间留一条窄气隙，铰链侧打开约 \(0.72\,\mathrm{rad}\)。顶部六根 U 形加热管带陶瓷端帽，管壁自发光强度跟加热指令走。后壁是十叶扭曲翼型风机，转速跟风机指令走。左侧蒸汽管通向双锥喷嘴；蒸汽指令大于 \(0.5\) 时，喷嘴锥与约 \(720\) 个加性粒子同时可见，基线蒸汽 \(0.15\) 只保留管路、不喷雾。右上七片排汽百叶随排汽指令张开。色调映射为 ACES，阴影为 PCF 软阴影。

食品沿厚度分成十六块几乎贴合的圆角薄片，与控制体一一对应。第 \(i\) 片的颜色由
\[
T_i=T_s-(T_s-T_{\mathrm{cold}})\,u_i^{1.15},\qquad u_i=i/15
\]
插值，\(T_s\) 与 \(T_{\mathrm{cold}}\) 来自当前帧日志。第 \(5\) 片对应脂肪夹层，用更深的色带标出。横向没有第二维梯度。指数 \(1.15\) 是显示约定。厚度滑条只改变几何缩放和所读数组。

演示读取 \texttt{catalog.json}，按策略、档位和厚度选择已经写出的数组，帧间隔 \(8\,\mathrm{s}\)，与附录\ref{app:trace} 的抽样一致。默认条件是组合档、对偶策略、肉糜 \(30\,\mathrm{mm}\)、初温 \(8^\circ\mathrm{C}\)、含水 \(0.72\)，对应种子 7。catalog 预写 \(36\) 条：四种策略乘三种档位再乘三种厚度，共 \(14904\) 帧。页面把四种策略与三种档位都做成下拉项，因此每条都在页面里可达；正文只引用其中的组合档对偶三条。这些数组由演示版工程核写出，开关与主表不同，差别在\ref{ch:sim}章的口径说明里给出。

页面分成三栏，顶栏之下另有一条仪表带。仪表带同时给出本帧时刻、冷点、进度、停机时刻、相对设计线的偏差和热阻方差。进度越过 \(0.85\) 时读数改成绿色，低于设计线时改成红色。左栏选择蒸、烤、组合与四种策略。中栏是腔体。右栏给出本帧的含水、进度、热阻与方差、腔温腔湿、水位，以及四个执行器的条形指示。路径 A/B/C 的显示量来自该帧已经写出的通量代理。请求与指令分两列，用来看见安全投影有没有改写加热；本次工作点上二者重合，因为加热器停在 \(196.5^\circ\mathrm{C}\)，低于 \(230^\circ\mathrm{C}\) 阈值。

底部曲线左轴为 \(0\)--\(180^\circ\mathrm{C}\)，右轴为进度 \(\alpha\in[0,1]\)，横轴为分钟；浅色竖带标出 \(150\)--\(190\,\mathrm{s}\) 探针窗。若打开对照策略，第二条冷点与进度以虚线叠在同一坐标上，用来直接看见开环菜单切断、腔温比例不停机、无探针提前停、对偶窗后方差下降这四件事。停机时刻取自当前轨迹的评分：\(30\,\mathrm{mm}\) 对偶组合约为 \(1864\,\mathrm{s}\)，\(50\,\mathrm{mm}\) 对偶组合为 \(3298\,\mathrm{s}\)，开环则落在菜单时间。门开关只改铰链开度，进入安全侧测量，不改已经写出的温度数组。

\section{主要结论}
\label{ch:conc}

把蒸和烤并入同一腔体之后，台面上少了一台机器，面板上多了三个档位名称。机器真正能改的，仍只有加热、蒸汽、排汽和风机。食品一旦进门，冷点、内部含水和反应进度都不在这四个旋钮上。一体机要回答的，是这一块食品的内部热阻有没有进入后验。

家用时域取 \(55\,\mathrm{min}\)。\(15\,\mathrm{mm}\) 开环菜单终点的 Fourier 数为 \(0.80\)，\(50\,\mathrm{mm}\) 为 \(0.12\)。同一套四个旋钮，薄件被菜单推过设计线，厚件停在设计线之下。厚度把整条带平移。策略名称、档位名称、食品名称，都排在厚度后面。

在十六条控制体的工程核上，下列陈述有日志或命题核对。

\begin{enumerate}
\item 平衡观测对内部热阻灵敏度为零。恒温段再密的腔温采样也不更新 \(R_{\mathrm{int}}\)。开环菜单失败的数学形式就在这里：菜单时间写在厚度档上，这一次过程里的热阻从未进入后验。
\item 两段相变变号加对流的探针提供第二个灵敏度方向。\(40\,\mathrm{s}\) 窗口在 \(30\,\mathrm{mm}\) 上的 Fourier 数为 \(8.9\times 10^{-3}\)，Biot 数在风机 \(0.4\) 时为 \(1.50\)、探针段升到 \(3.68\)。种子 7 在窗内冷点只从 \(8.01^\circ\mathrm{C}\) 升到 \(8.05^\circ\mathrm{C}\)。热量滞留在近表面；窗内收缩的是热阻方差，冷点几乎没有升温。
\item 开环按厚度给菜单：薄件过熟、厚件不足，S1 中位 \(e_{\alpha}=-0.843\)，未达比例 \(0.667\)。腔温比例闭合空气温度，不停机，能量中位 \(3310\)，进度停在上沿 \(+0.150\)。无探针未达比例 \(0.944\)，对偶 \(0.902\)：估计温度经常先于真值进度越过阈值。
\item 对偶策略在 \(150\)--\(190\,\mathrm{s}\) 的固定窗后，主对照 S1 的 \(4860\) 条样本全部把热阻方差从 \(0.64\) 降到 \(0.224\)；档位研究里更新的比例降到三分之二，未更新的 \(972\) 条全部落在蒸档，那里加热上限把探针窗的表面温差压掉了。厚件仍受扩散时间限制：档位研究里 \(50\,\mathrm{mm}\)、对偶、组合的中位 \(e_{\alpha}=-0.782\)，全部低于设计线。探针把方差乘下去，导热时间尺度没有走完。
\item 蒸、烤、组合只改变允许集合。蒸档加热上限 \(0.25\) 把对偶中位压在 \(-0.830\)；烤档与组合档的总体中位数为正，是因为 \(15\,\mathrm{mm}\) 和 \(30\,\mathrm{mm}\) 已经越过设计线，\(50\,\mathrm{mm}\) 三种档位全部低于 \(-0.2\)。读表时按厚度拆开。
\item 打开表面蒸汽压差使 \(15\,\mathrm{mm}\) 的 \(e_{\alpha}\) 中位上移 \(+0.647\)，使 \(50\,\mathrm{mm}\) 下移 \(-0.123\)。同一修正项的符号随厚度翻转。为冷点多送一股蒸汽，薄件上是冷凝收益，厚件上可能只是把表面打湿。
\item 安全削减的自变量不含进度估计。本次加热器平衡点 \(196.5^\circ\mathrm{C}\) 低于 \(230^\circ\mathrm{C}\) 阈值，削减在战役里不动作；规则仍与后验无关。水位、门、漏电和管温走另一条回路，品质模型改写不了断电条件。
\item 网格从 \(8\) 加密到 \(32\)，种子 7 在 \(1680\,\mathrm{s}\) 的冷点从 \(73.01^\circ\mathrm{C}\) 降到 \(68.87^\circ\mathrm{C}\)。主表固定十六条；八格会把 \(30\,\mathrm{mm}\) 对偶的停机偏差翻号。交叉表比较的是策略，不是格子厚度。
\item 初始含水三档与质量通道开/关给出零效应；脂肪夹层把 S2 中位从 \(-0.112\) 压到 \(-0.353\)。集合散布在 \(50\,\mathrm{mm}\) 上极差为 \(0\)。把 \(50\,\mathrm{mm}\) 时域从 \(55\,\mathrm{min}\) 放到 \(70\,\mathrm{min}\)，同一初值才走到设计线。时域不够和通量不够，在延长之后才分得清。
\end{enumerate}

五条设计性质落到已经运行的核上，轻重并不相同。可分离落实为固定窗的信息动作与其余时间的品质加热：\(150\)--\(190\,\mathrm{s}\) 蒸汽列跳到 \(1.0\)，窗外回到 \(0.15\)，加热列始终由饱和线性律给出。可拦截落实为加热器温度这一路，满功率平衡点低于阈值，规则待命。可重构依赖探针，热阻更新同时读取可安装通道和由真值温差构成的参照。可迁移保留了决策状态的分量定义，食品类别只改活度尺度和终端目标。可更新留在规格里：战役结束于日志，后验写回下一次先验需要另一次过程。

家用蒸烤一体机的面板通常写成蒸、烤、组合，再附带温度旋钮和时间旋钮。操作者得到的印象是：选一个档，定一个温度，等铃声。机器内部能改的仍是四个量。蒸档把加热请求夹在 \(0.25\) 以下，蒸汽可以离开零；烤档把蒸汽写成零，并把排汽抬到至少 \(0.45\)；组合档放开四个量。食品模块收到的是通量，不读取档位名称。种子 7、肉糜、\(30\,\mathrm{mm}\)、对偶策略下，组合档在 \(1866\,\mathrm{s}\) 停机，\(e_{\alpha}=+0.145\)，能量 \(1864\)；烤档关闭蒸汽后能量升到 \(2353\)，进度同样走到上沿；蒸档把加热夹在 \(0.25\)，进度停在 \(0.021\)，方差留在先验 \(0.64\)。档位改变的是四个量离开零的许可，不是冷点进度本身。

安全回路与品质回路在产品上必须分开。水位、门开关、剩余电流和加热器温度是硬测量：其中任何一条越过阈值，加热和蒸汽同时写成零。进度估计、热阻后验和冷点跟踪留在品质回路。家电面板上的“智能”若把这两侧混写进同一条加热请求，超温切断会随后验一起抖动。已经运行的核把品质请求和安全指令分成两列。IEC 60335-1 与 GB 4706.1 要求这些测量点存在\cite{iec60335,gb4706}。正文给出的是测量隔离的结构。

设计线 \(\alpha_m=0.85\) 对应恒温冷点上 \(F=3.794\,\mathrm{min}\)，用作策略比较的零点。它不是认证阈值，微生物初始数量不进入状态。停机看的是冷点和致死当量，不看全场的 \(L^2\) 范数，也不看腔温曲线画得有多密。面板上读到的“智能”，多数是把已经闭合的空气温度再画成一条更密的曲线。曲线再密，这一块食品的内部热阻仍然缺席。

\section{局限与后续工作}

数值核沿厚度用十六条控制体，界面潜热由蒸汽指令和活度的工程式给出。结壳变量累加，路径 C 在积分里接近零：S1 的初始含水达不到 \(0.45\) 的结壳门槛，家用组合档又把表面湿度维持得较高，褐变通道几乎不动作。GAB 清洁子集以淀粉类为主，肉类条数为 \(0\)；核里的活度是含水的单调饱和函数，与公开等温线同方向、不同反演。

估计器是标量跟踪器，不是集合滤波。第一个记录点出现 \(-7.92^\circ\mathrm{C}\)，来自先验热阻 \(5\) 的滞后上限。\(1200\,\mathrm{s}\) 时估计 \(61.27^\circ\mathrm{C}\) 高于冷点 \(46.65^\circ\mathrm{C}\)。对偶窗是 \(150\)--\(190\,\mathrm{s}\) 的时间表。无探针和对偶共用饱和线性加热律，所以两条策略的差别几乎全部来自那 \(40\,\mathrm{s}\) 里有没有把方差乘 \(0.35\)。\(r_{\mathrm{proxy}}\) 使用表面与冷点的真值温差；实施到机器上要改成可安装通道。两节点教师网络的留出均方根约 \(41^\circ\mathrm{C}\)，该网络没有接到控制器。

热阻更新目前仍读取由真值温差构成的参照。把参照换成可安装通道，只保留门、搁架和管壁上装得上的量，才是把可重构写严的第一步。给加热器另设初始温度或增益，主表里才能看见屏障真正改写指令。路径 A/B/C 需要在后验抽样上积分，符号稳定之后再生成解释句。多孔介质全场、集合滤波和有限时域求解器写在连续形式与估计器的完整定义里；评分循环用十六条控制体和标量跟踪器。战役结束于日志，后验写回下一次先验需要另一次过程。

方差更新是乘常数 \(0.35\) 的二值判断，结束方差只落在 \(0.64\) 与 \(0.224\) 两档。若改成与信息增益连续挂钩的协方差更新，分位图才会变成连续云，而不是两堆。S1 的初始含水达不到结壳门槛，表面褐变 \(\alpha_b\) 几乎全部为 \(0\)，蒸烤多目标冲突在数据上缺了一条腿。把表面对流蒸发系数放大，或增设一组低表层含水工况，才能跑出中心熟化度对表面褐变的帕累托前沿。一维核把冷点取成十六条中的最低温度；交叉验证给出两件事：二维最低温度落在与受热面正对的绝热远表面上，与几何中心相距 \(13.75\,\mathrm{mm}\)，那是半厚距离而不是横向偏移；二维冷点比一维只高 \(0.31\,\mathrm{K}\)，所以用一维最低格当冷点在温度上是够的，丢掉的只是横向位置。评分循环因此保留一维冷点定义，这一条在\ref{ch:physics}章有日志支撑。

开环按厚度给菜单，薄件过熟、厚件不足。腔温比例闭合空气温度，不停机。无探针经常在真值进度未到设计线时停止。对偶在 \(30\,\mathrm{mm}\) 上把中位误差从约 \(-0.53\) 拉到约 \(-0.08\)，\(50\,\mathrm{mm}\) 仍受扩散时间限制。菜单名称只出现在允许集合里。一体机真正要回答的，是内部热阻有没有被这一次过程看见。
